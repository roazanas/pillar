# Pillar Chess

Шахматный движок целиком на Pillar: семь модулей, 932 строки, без внешних
шахматных библиотек. Главный исходник — [main.plr](main.plr), горизонтальный вид —
[main.rplr](main.rplr).

## Запуск

Из корня репозитория:

```sh
cargo run --locked -- run examples/chess/main.plr
```

Для отдельного исполняемого файла:

```sh
cargo build --release --locked --bin plrc
target/release/plrc build examples/chess/main.plr --release -o target/pillar-chess
target/pillar-chess
```

На Windows добавьте `.exe` к именам исполняемых файлов. Нужен нативный C toolchain.

По умолчанию человек играет белыми против ИИ глубины 2. Вводите `e2e4`, `g1f3`,
`e1g1` для рокировки, `e7e8q` для превращения. Суффиксы: `n`, `b`, `r`, `q`;
без суффикса выбирается ферзь. Нелегальный ввод не меняет позицию.

Команды: `moves`, `hint`, `undo`, `save`, `claim`, `help`, `quit`.
`undo` отменяет пару ходов против ИИ или один полуход в режиме двух игроков.
`save` пишет текущие ходы в `pillar-chess.txt` в рабочем каталоге. `claim` принимает
ничью при уже возникшем троекратном повторении или 50 ходах без взятия и движения
пешек. Для выхода используйте `quit`: EOF является ошибкой ввода языка.

```sh
target/pillar-chess play 3 black
target/pillar-chess play 1 both
target/pillar-chess analyze 4 kiwipete
target/pillar-chess selfplay 2 20
target/pillar-chess replay e2e4 e7e5 g1f3 b8c6
```

## Проверки

```sh
target/pillar-chess selftest full
target/pillar-chess perft 4 start
target/pillar-chess divide 3 kiwipete
cargo test --locked --test chess
```

43 встроенные проверки охватывают шесть стандартных позиций, специальные ходы,
мат, пат, повторения, семантику значений, поиск мата и бюджет ИИ. Начальная позиция
на глубине 4 даёт **197 281**, `kiwipete` на глубине 3 — **97 862**.
Cargo-тест также проверяет игру, отмену, сохранение и неверные аргументы.
Подпроцессы ограничены 60 секундами и 128 КиБ вывода на поток.

## Устройство и ограничения

`position` хранит доску; `moves` проверяет легальность и считает perft; `search`
реализует alpha-beta с итеративным углублением и ограниченным quiescence.
`fixtures`, `selftest`, `ui` и `main` содержат позиции, проверки и интерфейс.
Оценка учитывает материал, активность, пешки, пару слонов и положение короля.

Глубина ИИ — 1–4; бюджет узлов — 12 000 на ход, 20 000 на анализ, 6 000 в selfplay.
Незавершённая итерация сохраняет предыдущий результат. Партия ограничена 512 полуходами.
Есть автоматические пятикратное повторение и правило 75 ходов; мат проверяется первым.
Поиск не учитывает историю повторений, игровой контроллер учитывает.

Это учебный движок: нет UCI, FEN/PGN-парсера, часов, дебютной книги и таблиц эндшпиля.
Сохранение использует координатную запись. Распознаются обычные случаи недостаточного
материала, но не все мёртвые позиции. Заявка на ничью по будущему ходу не реализована.

Правила: [FIDE](https://handbook.fide.com/chapter/E012023).
Позиции: [perft-набор Stockfish](https://github.com/official-stockfish/Stockfish/blob/master/tests/perft.sh).
Движок написан самостоятельно.
